Extract node candidates from bound IPA enhanced Markdown section contexts.
The response must be a single top-level JSON object with this shape:
{
  "schema_version": "kg.node_extraction.v1",
  "run_id": "node_real_or_mock_run_id",
  "mock": false,
  "batch_id": "batch_001",
  "nodes": [],
  "rejected_evidence": []
}
Do not output a top-level array, even when the batch has only one section.
Every node must include node_id, label, properties.evidence, properties.confidence, source_context_id, revision_round, status, and audit_refs.
Use distilled VA feedback only as repair guidance and never copy raw VA response.
Revision mode: when distilled_va_feedback is not empty, only return repaired nodes whose node_id is in distilled_va_feedback[].target_id. If a feedback item cannot be repaired faithfully, omit that node and return nodes: []. Do not add new nodes unrelated to distilled_va_feedback. Do not rewrite accepted nodes or rerun full extraction during revision mode.
For textbook evidence, write EvidenceRef objects with source_path, section, and quote_or_summary only. Do not include image_path, figure_id, or any image metadata in EvidenceRef.
Use the shortest useful source-faithful span from the enhanced Markdown for quote_or_summary; prefer direct textbook text whenever it supports the same fact.
Use section_contexts[].ipa_image_evidence only for figures. If an image is intrinsic to a node, put a FigureRef in properties.figures with image_path from ipa_image_evidence[].image_path, optional name from ipa_image_evidence[].name, and optional description from ipa_image_evidence[].description_text.
Do not fill FigureRef.figure_id. The pipeline backfills figure_id after extraction.
Do not create Image nodes. Do not reject a real image merely because it is visual rather than textual; include it in properties.figures when it belongs to the node.
Only cite real image_path values from section_contexts[].ipa_image_evidence. Do not invent figures or image paths.
For textbook evidence, copy the shortest useful source span itself, not an explanation of what the span says.
If visual text is long, noisy, tabular, grid-like, formula-heavy, or mostly OCR layout, do not put it in quote_or_summary; use a concise FigureRef.description when the image belongs to the node.
